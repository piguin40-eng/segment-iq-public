# Alcance de esta distribución

Esta copia pública fue solicitada por el titular del proyecto para descargar y conservar el software completo. Incluye el código propio, el protocolo y las skills redactadas para el laboratorio, el cliente, las pruebas y la documentación de preparación comercial.

No se ha añadido una licencia de código abierto ni una autorización comercial nueva. El cliente conserva su declaración `UNLICENSED`; los componentes externos mantienen sus propias licencias. La visibilidad pública no sustituye las condiciones pendientes de comercialización documentadas en `commercial/`.

No se distribuyen plugins ni scripts propietarios de Blender for Dental. El adaptador llama a una instalación local que debe aportar quien use el servidor. Tampoco se incluyen Blender, modelos de IA, claves de acceso ni historiales de casos.

Las referencias metodológicas a ejemplos conservan las lecciones generales y omiten identificadores privados. Los ejemplos completos y el corpus RAG del laboratorio siguen en su almacenamiento privado. Descargar esta copia no recupera automáticamente esa biblioteca.

Los paquetes Desktop Preview son clientes del servidor y mantienen su versión independiente. Desde 0.6.0 se ofrece además un instalador local para Mac Apple Silicon: prepara el servidor, el motor propio con Blender y los modelos en ese ordenador. Descarga los componentes desde sus proveedores conservando sus licencias; no incorpora ni activa B4D. El expediente comercial conserva sus pendientes y no acredita un producto sanitario aprobado ni una versión lista para venta.
